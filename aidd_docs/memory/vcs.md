# VCS

## Setup

- Main branch: `main`
- Platform: `github` ([BenjMichel/AI-launcher](https://github.com/BenjMichel/AI-launcher), public)

## Branches

- Format: `type/description-courte`
- Types in use: `feat`, `fix`, `chore`, `docs`, `test`, `refactor`

## Commits

- Convention: [Conventional Commits](https://www.conventionalcommits.org/)
- Format: `type(scope): description`
- Rules: mode impératif, minuscules, sujet de 72 caractères maximum
